Tag is the small pill for practice areas, project types and status.

- `ds-tag--bucket` is the outlined capitals tag for the three practice areas; show only the ones a project actually used.
- Project type: plain for In-house, `ds-tag--violet` for Volunteer, `ds-tag--lavender` for Concept. Pick one tint per project and keep it the same wherever the project appears.
- Status tags (`ok`, `warn`, `bad`, todo) always carry a word and a dot, never colour alone.
- Tags are not buttons. If it can be clicked, use Button.

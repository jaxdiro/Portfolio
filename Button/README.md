Button is the pill-shaped action control, in a lime call to action, forest, violet, outline and link variants.

- Use one `ds-btn--cta` (lime, with an arrow disc) per view for the main action, such as "View the work →".
- `ds-btn--forest` is for a second strong action beside it; `ds-btn--violet` for a friendly secondary such as "Say hello"; the plain outline button for everything else.
- `ds-btn--link` is a text action in `violet` for inline "Read the case study →" moments.
- Label text is `label` size, verbs first, sentence case. Disabled buttons drop to 45% opacity and stop responding.
- Focus shows a 2px `violet` ring (lime inside `forest` panels).

StatTile shows one big result number with a label and a comparison line.

- Provide a label (what was measured), the figure, and a short comparison ("about 22x the follower count").
- Plain `panel` tile by default. Use the `forest` tile for the single most important number on a view; its figure turns lime. Use the `lilac` tile for a number that makes a point by being small, such as $0.
- Never put more than one forest tile in a row. Figures use tabular numbers and the `stat` style.
- Real numbers only. When a metric is not available yet, show a dashed "metric pending" placeholder instead of a tile.
